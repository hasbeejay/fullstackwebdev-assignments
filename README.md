### 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/hasbeejay/fullstackwebdev-labtask.git
   ```

2. Open the repository folder in your preferred code editor.

3. Navigate to the required lab or assignment directory.

4. Open the relevant HTML file in a browser, or run the code using the appropriate environment for that task.
