### ✨ Landing Page Features

* 👋 **Welcome widget** — a time-of-day greeting for the instructor.
* 🕒 **Live clock** — analog clock with digital time, date, and time zone.
* 🪪 **Student information card** — displays student name, roll number, class, instructor, and university.
* 🗂️ **Assignment cards** — organized cards for assignments and lab tasks, featuring titles, descriptions, and relevant links.
* 🔗 **Direct access** — quick links to assignment source code and hosted demonstrations where available.
* 📄 **Assignment detail pages** — dedicated pages for individual assignments, with previous/next navigation.
* 🌗 **Light and dark mode** — follows the system theme with a manual toggle.
* 📱 **Responsive design** — adapts to desktops, tablets, and mobile devices.
* ♿ **Accessibility** — semantic HTML, visible focus states, a skip link, and reduced-motion support.
* ⚡ **Lightweight implementation** — plain HTML, CSS, and JavaScript without a build step.
